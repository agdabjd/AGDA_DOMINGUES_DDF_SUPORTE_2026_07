# Case Técnico – Dadosfera
Implementação de ambiente Linux, banco de dados MySQL, OpenVPN e preparação para integração com a plataforma Dadosfera.

---
## Sobre o projeto
Este repositório contém a implementação do case técnico proposto pela Dadosfera para avaliação de conhecimentos em infraestrutura Linux, bancos de dados relacionais, redes, VPN, SQL e documentação técnica.

Durante o desenvolvimento foram realizadas a preparação do ambiente em máquina virtual Ubuntu Server, instalação e configuração do MySQL, criação e população da base de dados, configuração do OpenVPN e documentação das atividades executadas, além das análises solicitadas utilizando consultas SQL.
